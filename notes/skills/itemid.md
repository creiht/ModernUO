# ItemID

**Item Identification (ItemID)** reveals the properties and value of unidentified items. It is the skill used by merchants and treasure hunters.

**Title:** Merchant | **Primary Stat:** Intelligence | **Secondary Stat:** Dexterity

**Source:** `Distribution/Data/skills.json`, `SkillsInfo.cs`

## Mechanics

- **Stat scaling:** None (zero across all stats)
- **Gain rates:** 1.0 Int gain per use (tied highest Int gain)
- **Primary use:** Identifying items

---

## Expansion Notes

ItemID is available from character creation in the base game. No expansion is required.
