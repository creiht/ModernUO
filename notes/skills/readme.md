# Skills

ModernUO features **58 skills** organized into four categories. Skills are the primary way characters develop capabilities beyond raw stats. Each skill has a minimum and maximum level, gain rates, and scaling relationships with core stats.

The skill cap system limits total skill points across all skills. The base cap is 7200 (720 per skill × 10 skills), with bonuses available through veteran rewards and certain items. Skills can be locked (no gain), raised, or lowered, allowing character optimization and specialization.

### Crafting Skills — 19 skills
Skills used to create items, modify equipment, and process resources.

### Utility Skills — 12 skills

- [Utility Skills](utility-skills.md) — Full list of all utility skills

## Key Concepts

- **Skill Cap**: Maximum total skill points (default 7200, adjustable)
- **Locks**: Skills can be Raised, Locked, or Lowered
- **Gain Rates**: Each skill has unique gain chances based on skill level and target level
- **Stat Scaling**: Many skills scale with Str/Dex/Int differently
