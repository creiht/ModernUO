## Notes

- **Expansion-gated skills** (49-57: Necromancy, Focus, Chivalry, Bushido, Ninjitsu, Spellweaving, Mysticism, Imbuing, Throwing) have zero stat scales and zero gain modifiers — they are "pure" skills unaffected by stats.
- **GainFactor** is uniformly 4 across all 58 skills in the current data.
- **Stat scales** are stored as decimals (e.g., 0.05 = 5% per stat point), already divided by 100.0 from the raw JSON values.
- **StatTotal** in the JSON represents the maximum total stat influence bonus (sum of all scale values × 100), capped at 50 for the highest-skill skills.
