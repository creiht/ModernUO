# Expansions

ModernUO supports **12 expansion levels** (0–11) with a cumulative design — each expansion adds features on top of all previous ones. Players with higher expansion flags enabled have access to additional content.

## Expansion Levels

| Level | Expansion | Key Features |
|-------|-----------|-------------|
| 0 | Base | Original UO content |
| 1 | T2A (Third Age) | Bushido skills/spells, Statues, Gargoyles intro |
| 2 | SE (Seeds of Enlightenment) | Spellweaving, new creatures, quests |
| 3 | AOS (Age of Shadows) | Mysticism, ninjitsu, ethics, new maps |
| 4 | MC (Mondain's Legacy) | Artisans, new crafting skills, items |
| 5 | SB (Steal Born) | ? |
| 6–10 | ? | Additional expansion content |
| 11 | EJ (Event Journal) | Latest release features |

## Map Availability

Different maps become available at different expansion levels:

- **Felucca** — Available from expansion 0
- **Trammel** — Available from expansion 1
- **Ilshenar** — Available from expansion 3 (AOS)
- **Malas** — Available from expansion 3 (AOS)
- **Tokuno** — Available from expansion 1 (T2A)
- **TerMur** — Available from expansion 3 (AOS)

## Key Expansion Features

### Races
- **Human** — Base expansion
- **Elf** — T2A
- **Gargoyle** — AOS

### Skills by Expansion
- **T2A**: Bushido (8 skills)
- **AOS**: Mysticism (10 skills), Ninjitsu (12 skills)
- **MC**: Artisan skills added

### New Maps
Each expansion added new explorable areas with unique creatures, resources, and dungeons.

### Cumulative Design
ModernUO uses a cumulative expansion model — enabling a higher expansion level automatically grants all features from lower levels. This simplifies server configuration and ensures feature compatibility.
