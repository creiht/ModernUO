# Expansions

ModernUO supports **12 expansion levels** (0–11) with a cumulative design — each expansion adds features on top of all previous ones. Players with higher expansion flags enabled have access to additional content.

## Expansion Levels

| Level | Expansion | Key Features |
|-------|-----------|-------------|
| 0 | None | Original UO content |
| 1 | T2A (The Second Age) | Bushido skills/spells, Statues, Tokuno, Elves |
| 2 | UOR (Renaissance) | Spellweaving, new creatures |
| 3 | UOTD (Third Dawn) | Sea-themed content |
| 4 | LBR (Lord Blackthorn's Revenge) | New maps, creatures |
| 5 | AOS (Age of Shadows) | Mysticism, Ninjitsu, Ethics, Virtues, AOS stats, Ilshenar/Malas/TerMur |
| 6 | SE (Samurai Empire) | Bushido refinement, new spells |
| 7 | ML (Mondain's Legacy) | Quest system, bonus harvest, Parasitic/Darkglow poisons, skill cap bonus |
| 8 | SA (Stygian Abyss) | Gothic/Rustic housing themes |
| 9 | HS (High Seas) | Additional content |
| 10 | TOL (Time of Legends) | Jungle/Shadowguard themes, full Gargoyle content |
| 11 | EJ (Endless Journey) | Latest release features |

## Map Availability

Different maps become available at different expansion levels:

- **Felucca** — Available from Base (expansion 0)
- **Trammel** — Available from Base (expansion 0)
- **Tokuno** — Available from T2A (expansion 1)
- **Ilshenar** — Available from AOS (expansion 5)
- **Malas** — Available from AOS (expansion 5)
- **TerMur** — Available from AOS (expansion 5)

## Key Expansion Features

### Races
- **Human** — Base expansion
- **Elf** — T2A
- **Gargoyle** — TOL

### Skills by Expansion
- **T2A**: Bushido spell school (8 spells)
- **AOS**: Mysticism skill (8 magical skills), Ninjitsu spell school (10 spells)
- **ML**: Mondain's Legacy (ML)

### New Maps
Each expansion added new explorable areas with unique creatures, resources, and dungeons.

### Cumulative Design
ModernUO uses a cumulative expansion model — enabling a higher expansion level automatically grants all features from lower levels. This simplifies server configuration and ensures feature compatibility.
